# PreçoCerto

Projeto da disciplina **Introdução ao Desenvolvimento para Dispositivos Móveis** (Afya Centro Universitário Ji-Paraná). Professor: Romário Vitorino Ferreira.

## Problema

Muitos pequenos empreendedores de alimentação (hamburguerias, pizzarias, confeitarias) definem seus preços sem conhecer o custo real dos produtos, o que gera prejuízo e margens baixas.

## Objetivo

Aplicação web que calcula o custo, o preço de venda sugerido, o lucro e a margem de cada produto.

## Funcionalidades previstas

- Calcular preço de venda a partir de custos, taxas, impostos e margem
- Cadastrar e listar produtos
- Copiar o resultado (Clipboard API)
