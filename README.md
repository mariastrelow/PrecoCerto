\# \*PreçoCerto\*

O PreçoCerto é um projeto acadêmico desenvolvido na disciplina de Introdução ao Desenvolvimento para Dispositivos Móveis, da Afya Centro Universitário de Ji-Paraná, orientado pelo professor Romário Vitorino Ferreira.

\## \*Sobre o projeto\*

O projeto surgiu ao percebermos que muitos pequenos empreendedores do setor alimentício têm dificuldade em definir o preço de seus produtos. Muitas vezes, gastos com ingredientes, embalagens e taxas acabam não sendo considerados corretamente, o que pode gerar prejuízos.



Pensando nisso, desenvolvemos uma aplicação web que facilita a precificação dos produtos, permitindo que o usuário tenha uma visão mais clara dos seus custos e lucros.



\## \*Funcionalidades\*

\- Dashboard com informações e gráficos sobre os produtos cadastrados;

\- Calculadora de custo, preço de venda, lucro e margem;

\- Cadastro, edição e exclusão de produtos;

\- Busca e filtro por categoria;

\- Armazenamento dos dados no navegador;

\- Cópia dos resultados;

\- Funcionamento offline após o primeiro carregamento;

\- Interface adaptada para computadores e celulares.



\## \*Como funciona o cálculo?\*

O usuário informa o custo dos ingredientes, da embalagem, as taxas e a margem de lucro desejada. Com essas informações, o sistema calcula automaticamente o preço de venda sugerido.



Por exemplo, um produto com custo de R$ 13,00, taxas de 10% e margem de lucro de 30% terá um preço de venda sugerido de R$ 21,67.



\## \*Tecnologias utilizadas\*

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript puro, além de recursos como localStorage, Fetch API, Clipboard API e Service Worker.



\## \*Como executar\*

Para utilizar o sistema, basta clonar o \[repositório do projeto](https://github.com/mariastrelow/PrecoCerto.git), abrir a pasta no Visual Studio Code e executar o arquivo index.html utilizando a extensão Live Server.



\## \*Testes\*

Os testes envolvem a navegação entre telas, validação dos campos, cálculos, cadastro de produtos, armazenamento dos dados, funcionamento offline e adaptação para dispositivos móveis. As evidências estão disponíveis na pasta docs/evidencias/.



\## \*Limitações e cuidados\*

O sistema não possui login, sincronização entre dispositivos ou coleta de dados pessoais. As informações ficam armazenadas no próprio navegador.



Além disso, os cálculos não consideram despesas fixas, como aluguel, energia e funcionários.



O PreçoCerto possui finalidade exclusivamente acadêmica. Os valores apresentados são estimativas e não substituem a orientação de um contador.
